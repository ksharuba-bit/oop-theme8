## Тема проєкту
**Розроблення інформаційної системи для статистичного аналізу футбольних турнірів із використанням технології об'єктно-орієнтованого програмування**

## Виконані завдання

### Завдання 2 — клас `Student`
Створення масиву студентів, обчислення середнього бала, сортування за середнім балом та відбір студентів, які мають лише оцінки 4 або 5.

Файл: `task2_student.cpp`

### Завдання 3 — клас комплексних чисел
Реалізовано додавання, віднімання, множення, ділення, спряження, піднесення до степеня та добування квадратного кореня.

Файл: `task3_complex.cpp`

### Завдання 4 — клас `Train`
Реалізовано масив поїздів, сортування за номером, пошук за пунктом призначення та сортування за пунктом призначення і часом відправлення.

Файл: `task4_train.cpp`
